# Customization checklist

## Before editing

- [ ] Duplicate this folder or copy the files into the intended GitHub profile repository.
- [ ] Confirm the GitHub profile repository name matches the account username.
- [ ] Open the SVGs in Figma and create color styles from `assets/design-tokens.css`.

## Personalize

- [ ] Replace `[Your Name]`, `[username]`, and all example URLs in `docs/README-EXAMPLE.md`.
- [ ] Rewrite the one-line identity and current-focus statement in your own voice.
- [ ] Confirm the roadmap reflects your actual sequence: foundations → software engineering → production systems → AI engineering → product building.
- [ ] Mark the current stage clearly with both a visual highlight and a text label.
- [ ] Adjust or replace line icons while keeping the minimal outline style consistent.
- [ ] Change colors centrally in the token sheet and update the corresponding SVG/Figma colors.
- [ ] Review sizing and wrapping at a narrow/mobile viewport.
- [ ] Check color contrast and text legibility.

## Prepare assets

- [ ] Edit `hero.svg`, `roadmap.svg`, and `divider.svg` in Figma; preserve editable source layers.
- [ ] Export updated SVGs and confirm they retain a `viewBox` and meaningful dimensions.
- [ ] Verify that each SVG opens in a browser and renders as expected.
- [ ] Keep both authored source and optimized output if optimization changes the editable file.

## Publish

- [ ] Copy `docs/README-EXAMPLE.md` into the profile repository as `README.md`.
- [ ] Update every image path to match the final repository folders and filenames.
- [ ] Ensure the artwork is committed to a publicly accessible location supported by GitHub.
- [ ] Preview the README on GitHub and inspect both wide and narrow layouts.
- [ ] Confirm there are no placeholder values, broken links, or private details.
- [ ] Confirm the README remains roadmap-first and contains no project showcase section.
- [ ] Commit the final README and assets with a descriptive Git message.
