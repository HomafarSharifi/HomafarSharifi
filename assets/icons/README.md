# README icon set

These icons are adapted from the official [Lucide](https://lucide.dev/) SVG set by Lucide Icons and Contributors. They share Lucide's 24 × 24 viewBox, 2 px rounded outline, and the profile's electric blue accent (`#3B82F6`).

Original SVG sources are in the [Lucide icons repository](https://github.com/lucide-icons/lucide/tree/main/icons). Lucide is distributed under the [ISC License](https://lucide.dev/license).
